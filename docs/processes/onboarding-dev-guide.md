# Entwickler-Onboarding

> **Hinweis:** Die kompakte Anleitung zur Installation und die ersten Schritte für Entwickler befinden sich zusammen mit dem Technologieüberblick direkt in **[tecstack.md](tecstack.md)**.

### Schnellstart-Zusammenfassung:
```bash
cd app
npm ci
npm run prepare:java-compiler
npm run dev
```
Server läuft auf: `http://localhost:5173`.
