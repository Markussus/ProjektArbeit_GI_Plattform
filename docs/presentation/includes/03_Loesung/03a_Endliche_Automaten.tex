\begin{itemframe}{Endliche Automaten -- Überblick}
  \item Studierende definieren \textbf{DFA und NFA} selbst und führen ein Eingabewort Schritt für Schritt aus.
  \item Jeder Schritt erscheint gleichzeitig in \textbf{Übergangstabelle} und \textbf{Zustandsdiagramm}.
  \item Ein \textbf{Stapeltest} prüft mehrere Wörter auf einmal -- erkennt der Automat die beabsichtigte Sprache?
  \item Ein Automat lässt sich aus einer \textbf{rechtslinearen Grammatik} erzeugen.
  \item Übungen geben eine automatische Rückmeldung mit Gegenbeispiel.
\end{itemframe}
\note{%
  Einstieg: Das Thema verbindet die formale Definition mit ihrer grafischen Darstellung.
  Kurz halten -- die Details kommen auf den nächsten beiden Folien.
  Überleitung: "Zwei Entscheidungen haben den Aufbau geprägt -- eine in der Architektur, eine im UI."
}

  Antwort: didaktisch -- Studierende sollen Determinismusverstöße gemeldet bekommen.
