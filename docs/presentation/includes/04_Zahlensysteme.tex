\begin{itemframe}{Zahlensysteme konfigurieren}
  \item Fünf Modi: \textit{Integers}, \textit{Negative}, \textit{Fractional}, \textit{IEEE-754} und \textit{Arithmetik} -- Übung oder Beispiel ordnet sich automatisch dem passenden Modus zu
  \item Eingaben je nach Basis mit Regex-Filtern validiert, Bitlänge explizit begrenzt
  \item Negative Zahlen in fester 8-Bit-Breite (Wertebereich $-128$ bis $127$, abgestimmt auf die Vorlesung)
  \item Berechnungen durchgängig mit \texttt{BigInt} statt \texttt{Number}: keine Rundungsfehler bei großen Zahlen
  \item 10 Übungen und 36 vorlesungsbegleitende Beispiele mit automatischer Rückmeldung

                \note{
                  \textbf{Person: }

                    \item Einstieg: Das Modul deckt den Zahlenbereich der Vorlesung ab -- von der Basisumrechnung
                    \item bis zur Gleitkommadarstellung.
                    \item Die BigInt-Entscheidung kurz begründen: Number verliert ab 2\textasciicircum53 an Präzision.
                    \item Überleitung: "Wie läuft so eine Simulation konkret ab?"
                  \end{itemize}
                }
\end{itemframe}
